# Детектирование аномалий в логах распределенных систем

Годовой проект магистратуры «Искусственный интеллект», ФКН НИУ ВШЭ, 2026/27.
Тема 85 «Детектирование аномалий в данных распределенных облаков».

## Задача

Узлы распределенной системы пишут логи — текстовые журналы событий. Сбоев в
кластере много, они разнообразны, и размеченных данных почти нет. Цель проекта —
построить модель, которая выучивает **нормальное** поведение системы по логам и
находит сессии, которые на него не похожи.

Конвейер:

```
сырые логи → парсинг в шаблоны → сессии / окна → признаки или последовательности
           → модель нормы → оценка аномальности → порог → норма / аномалия
```

Ключевые принципы, согласованные с куратором:

- модели учатся на нормальных данных, метки нужны только для проверки;
- главная метрика — **recall**: пропущенный сбой дороже ложной тревоги;
- порог выбирается под целевой recall, а не под максимум F1;
- движение от простых методов (PCA, Isolation Forest) к нейросетевым
  (DeepLog, LogAnomaly, трансформеры).

## Данные

Основной датасет — **HDFS_v1** из [loghub](https://github.com/logpai/loghub):
логи распределенной файловой системы Hadoop, 11 млн строк, 575 061 сессия
(блок), 2.93% аномальных, разметка по блокам.
